Langchain is an open-source orchestration framework that is used for the developement of applications that use LLMs. Langchain stremlines the programming of LLM applications through abstractions.


Components:
 - document loaders
 - text splitters
 - vector database
 - prompt template 
 - models
 - tools

 Chains
  - assemble components to accomplish specific task (e.g.,summarize docs, query SQl DB)
  
Agents
 - figures out what it needs to do, then executes (e.g., customer service agent)
 - reasoning engine to determine which actions to take

 Langchain modules -> models, prompts, indexes, memory, chains,agents

 * Models
  - Language models
  - Text embedding models

* Prompts
input to a model,i.e., instruction given to the LLM

* Indexes (document loader, vector databases, text splitters)

* Memory
  - have simple utilities to retain the chat history into your application
