# LOG CLASSIFICATION WITH HYBRID CLASSIFICATION FRAMEWORK

This project implements a hybrid log classification system, combining three complementary approaches to handle varying levels of complexity in log patterns. The classification methods ensure flexibility and effectiveness in processing predictable as well as complex data patterns.

##CLASSIFICATION APPROACHES

1) **Regular Expression (Regex)**
 - Handles the most simplified and predictable patterns
 - Useful for patterns that are easily captured using predefined rules

2) **Sentence Transformer (BERT) + Logistic Regression**
 - Manages complex patterns when there is sufficient training data.
 - Utilizes embedding generated by Sentence Transformers and applies Logistic Regression as the classification layer.

 3) **LLM**
  - Used for handling complex patterns when sufficient labeled training data is not available.
  - Act as a backup approach
